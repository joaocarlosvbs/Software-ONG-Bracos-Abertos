# Software-ONG-Braços-Abertos
Documentação do software desenvolvido para a ONG Braços Abertos Brasil - Iniciativa para a curricularização da Extensão do 3° ano do curso de ciência da computação da FEMA de Assis. Além do projeto de extensão, contém o código utilizado, bem como a documentação do software. Para uso livre da ONG ao término do projeto.
